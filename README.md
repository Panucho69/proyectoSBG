# Mi primer proyecto de Git

Este repositorio contiene mi primer proyecto administrado con Git y GitHub. Es un sitio web personal en el que presento información sobre mi identidad, portafolio, currículum y formas de contacto.

## Autor

**Samuel Gallegos**

## Tecnologías utilizadas

- HTML5
- CSS3
- Git
- GitHub

## Contenido del proyecto

- `index.html`: página principal.
- `identidad.html`: información personal.
- `portafolio.html`: presentación de proyectos y trabajos.
- `cvu.html`: currículum.
- `acerca.html`: descripción del autor.
- `contactanos.html`: información de contacto.
- `css/style.css`: estilos visuales del sitio.
- `img/`: imágenes utilizadas en las páginas.

## Cómo visualizarlo

1. Clona el repositorio:

   ```bash
   git clone git@github.com:Panucho69/proyectoSBG.git
   ```

2. Entra en la carpeta:

   ```bash
   cd proyectoSBG
   ```

3. Abre `index.html` en tu navegador o utiliza la extensión Live Server de Visual Studio Code.

## Objetivo

Practicar el desarrollo web y aprender el flujo de trabajo de Git: crear ramas, registrar cambios mediante commits y compartir el proyecto en GitHub.
